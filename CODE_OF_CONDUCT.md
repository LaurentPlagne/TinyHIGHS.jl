# Code of Conduct

We want TinyHiGHS.jl to be a welcoming, technically rigorous project. Please
be respectful, assume good intent, and focus criticism on ideas and code rather
than people.

Unacceptable behaviour includes harassment, discrimination, personal attacks,
and publishing private information without consent. Maintainers may remove
comments or contributions that violate these expectations.

Report a concern privately to the repository maintainer, or open a GitHub issue
when the report is not sensitive. All reports will be handled as confidentially
as practical.
